# Air Quality Analysis Project

## Objective
To analyze air pollution data and identify pollution levels in different cities.

## Technologies Used
- Python
- Pandas
- Matplotlib
- VS Code

## Project Steps
1. Dataset loading
2. Data cleaning
3. Handling missing values
4. Removing duplicate records
5. Statistical analysis
6. Data visualization
7. Identifying top 10 polluted cities

## Output
- Cleaned dataset
- Pollution distribution graph
- Top 10 cities pollution graph

## Conclusion
This project helps understand air pollution levels and compare pollution across different cities.
